# Online Learning Platform

An Online Learning Platform developed using HTML, CSS, JavaScript, Java, and Spring Boot. This project allows students to explore courses, register/login, and access learning content through a responsive web application.

---

## Features

- User Registration and Login
- Responsive Homepage
- Course Listing Section
- Modern UI Design
- Frontend and Backend Integration
- REST API Support
- Student Dashboard
- Authentication Pages

---

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- REST API
- Maven
